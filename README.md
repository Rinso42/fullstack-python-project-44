# Brain Games

«Игры разума» — набор из пяти консольных игр по мотивам популярных мобильных приложений для тренировки мозга. Каждая игра задаёт вопросы, на которые нужно дать правильные ответы. После трёх правильных ответов игра считается пройденной; неправильный ответ завершает игру и предлагает пройти её заново.

## Требования

Для запуска необходимы:
- Node.js 20 или выше
- npm

## Установка

Склонируйте репозиторий:
git clone https://github.com/Rinso42/fullstack-python-project-44.git

Перейдите в директорию проекта:
cd fullstack-python-project-44

Установите зависимости:
npm install

Установите пакет и его консольные команды в систему:
npm link

После установки доступны следующие игры:
brain-even - Определите, является ли заданное число чётным.
brain-calc - Вычислите результат заданного математического выражения.
brain-gcd - Найдите наибольший общий делитель двух заданных чисел.
brain-progression - Определите пропущенное число в арифметической прогрессии.
brain-prime - brain-prime
